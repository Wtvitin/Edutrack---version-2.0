# Integrations Catalog

## ADDED Requirements

### Requirement: catálogo frontend documentado

O sistema MUST documentar o catálogo de seis integrações, busca normalizada,
filtros, estados disponível/planejado e links oficiais sem secrets.

#### Scenario: proposta planejada

- WHEN uma integração planejada é selecionada
- THEN a UI MUST apresentar proposta informativa sem simular conexão.
